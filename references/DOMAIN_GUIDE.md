# 测评蓝图与试卷质量审查领域指南

## 业务问题

试卷常能覆盖知识点，却缺少蓝图、认知层级、题型比例、评分一致性和时间适配检查。

## 产品解决方案

在试卷生成后或已有试卷上建立测评蓝图并审查覆盖、难度、题型、分值和作答时间。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `assessment_purpose` | 测评用途 | 是 | 单元诊断、期中期末或分层 |
| `exam_paper` | 试卷与题目 | 是 | 完整题面 |
| `answer_key` | 答案与评分标准 | 是 | 包括分值和评分锚点 |
| `learning_objectives` | 学习目标 | 是 | 测评需要覆盖的目标 |
| `knowledge_points` | 知识点与课时 | 是 | 知识点、课时和重要度 |
| `duration` | 考试时长 | 是 | 分钟 |
| `student_level` | 学生群体 | 是 | 年级、班型和基础范围 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

业务负责人应确认：输入事实、关键假设和最终成果适用范围。未经确认的内容只能作为草案。

## 主要风险

难度和区分度不能只靠模型估计；需要真实试做数据；不得把无证据估计写成测量学结论。
