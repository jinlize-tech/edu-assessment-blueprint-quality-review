# JLZ-EDU-SK-085 Codex执行任务书

## 1. 基线

- 任务编号：`JLZ-EDU-EXPANSION-30-FULL-DELIVERY`
- 候选来源：`CAND-013`
- 正式产品：`JLZ-EDU-SK-085` / 测评蓝图与试卷质量审查
- 类型：Skill
- 批次：2
- 业务中心：10 教学质量与学习证据中心
- 版本基线：`EDUCATION_BASELINE_V1.0.0`
- 产品版本：`1.0.0`
- 许可证：Apache-2.0

## 2. 用户、痛点与目标

- 用户：教研组长、命题教师、教学主管、测评负责人
- 痛点：试卷常能覆盖知识点，却缺少蓝图、认知层级、题型比例、评分一致性和时间适配检查。
- 目标：在试卷生成后或已有试卷上建立测评蓝图并审查覆盖、难度、题型、分值和作答时间。

## 3. 输入契约

| 键 | 名称 | 类型 | 必填 |
|---|---|---|---|
| `assessment_purpose` | 测评用途 | string | 是 |
| `exam_paper` | 试卷与题目 | string | 是 |
| `answer_key` | 答案与评分标准 | string | 是 |
| `learning_objectives` | 学习目标 | array | 是 |
| `knowledge_points` | 知识点与课时 | array | 是 |
| `duration` | 考试时长 | integer | 是 |
| `student_level` | 学生群体 | string | 是 |

## 4. 工作流

1. 明确用途
2. 建立蓝图
3. 标注题目属性
4. 检查覆盖与配比
5. 审查时间与评分
6. 标记风险题
7. 输出修订建议

## 5. 阶段状态

| 阶段 | 动作 | 退出成果 |
|---|---|---|
| S1_SCOPE_CONFIRMATION | 确认目标、校区/岗位/课程范围、期限、交付格式和可用资料。 | 任务确认单与最多3个关键缺口 |
| S2_EVIDENCE_INVENTORY | 盘点试卷、答案与评分标准、单元目标、知识点清单、教学课时、学生水平、考试时长，标记来源、版本、敏感字段与冲突。 | 证据清单、缺口表和冲突表 |
| S3_PROFESSIONAL_DIAGNOSIS | 围绕在试卷生成后或已有试卷上建立测评蓝图并审查覆盖、难度、题型、分值和作答时间。进行专业诊断，形成问题树和优先级。 | 问题树、风险和优先级 |
| S4_SOLUTION_DESIGN | 按明确用途 → 建立蓝图 → 标注题目属性 → 检查覆盖与配比 → 审查时间与评分 → 标记风险题 → 输出修订建议设计首选方案和受限备选方案。 | 方案、责任人、完成标准 |
| S5_HUMAN_CONFIRMATION | 由业务负责人复核输入事实、关键假设和最终成果适用范围。 | 确认记录、未决项和升级项 |
| S6_FINAL_DELIVERY | 生成完整交付成果，执行结构、证据、安全、品牌和独立安装检查。 | 最终成果、范围限制和复盘指标 |

## 6. 核心成果

- `测评蓝图`
- `题目属性表`
- `覆盖缺口`

## 7. 差异化与排重

- 与现有产品：现有单元测评和试卷生成负责出题；本产品负责测量质量和蓝图审查，可直接检查人工试卷。
- 排重检查：部分重叠；共享题目与知识点字段，但本产品不主要生成题目，输出蓝图与质量风险。
- 独立理由：可独立审核任何试卷，不依赖题库或生成器。

## 8. 安全与人工门禁

- 复核角色：业务负责人
- 复核范围：输入事实、关键假设和最终成果适用范围
- 不调用外部收费API。
- 不自动修改外部系统、执行退款、审批合同、处分员工或联系外部人员。
- 高风险产品完成状态必须确认人工复核。
